# 기능 요청: 마감일 임박 태스크 알림

**작성자:** (팀장, 퇴사 전 마지막 커밋)
**상태:** 미착수

## 요구사항

- 마감일이 3일 이내로 남은 태스크 목록을 반환하는 엔드포인트 추가
  - `GET /api/tasks/upcoming?days=3`
- 이미 마감이 지난 태스크는 `getOverdueTasks`로 별도 조회 가능 (구현되어 있음)
- 응답 형식은 기존 `/api/tasks` 와 동일한 `{ data: [...] }` 형태 유지

## 참고사항

- 기존 `getOverdueTasks` 구현체를 참고해서 패턴 맞추면 될 듯
- ⚠️ 주의: 날짜 관련 로직 손댈 때 기존 dueDate 포맷 확인 필요 (일관성이 없어 보임)
